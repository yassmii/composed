Keep cohort summaries separate. Use sequential execution and bounded per-run/total deadline/output; these bounds are not an exact dollar cap. Same runtime, requested model, effort, permissions, task prompt, initial application files, grader and available tools across each pair. Balance each task baseline→kit in one repetition and kit→baseline in the other. Freeze corpus/protocol/grader hashes before measured runs; do not tune skills or graders against confirmation results. Native tool availability and CLI account readiness are verified before dispatch.

Calibration uses known-correct references, untouched failing seeds and plausible semantic mutants. Protected graders/public regression checks run against selected delivered source copies, not agent-edited test scripts. Graders are withheld from supplied agent workspaces, not claimed to be adversarially inaccessible.

Report task acceptance and regressions separately from execution completion. Record exact input/output bytes, runtime/config versions, wall time, available usage, observed human interventions, blocked/failed/not_run results and all attempts. Keep private prompts/tool traces local and ignored by default; use only synthetic data for the pilot and publish bounded reports in the authorised repository scope.
