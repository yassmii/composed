# Multi-agent default in the generic Build Kit

Request: require real delegation for complex implementation instead of silently
continuing in a single-agent or self-review mode.

Scope: portable FR/EN doctrine, orchestration/review skills, runtime-aware
bridges, catalog, documentation, release metadata and regression checks.
Simple questions and bounded small fixes stay direct. A user's explicit
single-agent instruction overrides the default and is recorded honestly.

The kit cannot create runtime tools or permissions. Missing native delegation
blocks implementation subject to this policy; it does not imply fabricated
agents or automatic configuration changes. No product contract changes.

Primary skill: delivery-orchestrator. Verification: native typecheck, Build Kit
tests, catalog validation and fixture eval (structural evidence, not proof that
a real external runtime obeyed the instructions).
